## 2. Excel 백데이터 템플릿 연동 요청 (예정 작업)
현재 구현된 웹페이지 구조를 최대한 유지하면서 표준 백데이터 템플릿(ChatGPT 설계안)을 연동한다.

1. Excel 각 시트의 컬럼을 인식하여 선사별 운임, LOCAL CHARGE, PORT REMARK 등을 DB에 등록
2. POL/POD, 컨테이너 TYPE, 수량에 따른 유효 운임 자동 검색
3. 과금 단위 및 O/F 포함 항목을 고려한 비용 자동 산출
4. 운임 만료, 비용 누락, 중복 등록 시 경고 표시
5. 계산 결과를 고객 제출용 Excel 견적서로 출력

### 진행 원칙
- 첨부 템플릿의 시트명·컬럼명을 기준으로 데이터 구조를 정의
- **먼저 현재 데이터 모델(`DATA_MODEL.md`)과 비교표 작성** → 그대로 연결 / 이름만 다름(별칭) / 신규 컬럼 / 신규 개념으로 분류 → 확인 후 적용
- 기존 템플릿과 새 템플릿을 모두 인식하도록 단계별 적용, 단계마다 기존 테스트(19건) + 신규 테스트 실행
- 실제 등록되지 않은 운임이나 부대비용은 임의 생성하지 않고 "확인 필요(TBA)" 상태로 처리
